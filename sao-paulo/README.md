# São Paulo, com você

Uma pequena carta de amor interativa para **Sumercé Linda**.

**Site:** https://esteargmartacosta.github.io/Mari/sao-paulo/

## A experiência

Este cantinho foi pensado para ser aberto no celular, como um presente discreto e carinhoso:

- Um horizonte ilustrado de São Paulo e três cartões poéticos inspirados na Paulista, no Ibirapuera e na Liberdade.
- Cinco capítulos, de 18 a 22 de novembro de 2026, cada um com um bilhete de bom dia, outro de boa noite e uma canção.
- Seis envelopes escondidos, cujo progresso permanece salvo no próprio navegador.
- Uma constelação de cinco elogios.
- Uma carta final que pode ser aberta a qualquer momento, além de um segredo que aparece ao abrir todos os envelopes.
- Modo de luz suave, pétalas, animações delicadas e respeito à preferência por movimento reduzido.

## Como editar

O site é **um único arquivo**, `index.html`, sem frameworks, compilação ou dependências de JavaScript. Para editar os textos de cada dia, procure por `var days=` no final do arquivo. Para editar os segredinhos, procure por `class="secret"`. Para editar a carta final, procure por `id="letter-modal"`.

Os links das músicas levam à busca correspondente no YouTube. Não há reprodução automática.

## Publicação

Este diretório fica separado do livro presente na raiz do repositório `Mari`. O GitHub Pages usa o mesmo domínio e publica este site no subdiretório `/Mari/sao-paulo/`.
