# Mariana floresce

Algumas pessoas recebem flores. Mariana recebeu um jardim que aprende a nascer com ela.

## Publicar no GitHub Pages

1. Crie um repositório chamado `mariana-floresce`.
2. Envie todos os arquivos desta pasta para a raiz do repositório.
3. Abra `Settings`, depois `Pages`.
4. Em `Build and deployment`, escolha `Deploy from a branch`.
5. Selecione a branch `main` e a pasta `/ root`.
6. Salve.

A página ficará disponível no endereço exibido pelo GitHub Pages.

Não é necessário instalar dependências nem executar build.
